Subscription Management Platform
Project Overview

A full stack SaaS Subscription Management Platform designed to manage user subscriptions, payment tracking, renewal reminders, and analytics efficiently. The platform provides secure authentication, a responsive user interface, and real-time subscription insights for better business management.

Features
Secure user authentication and authorization
Subscription and payment management
Renewal reminders and notifications
Analytics dashboard with subscription insights
Responsive and user-friendly UI
CRUD operations for subscription plans
Real-time data handling
Technologies Used
React.js
Node.js
Express.js
MongoDB
JWT Authentication
Bootstrap / CSS
Project Workflow
User registration and login
Create and manage subscription plans
Track payments and subscription status
View analytics and reports
Receive renewal reminders and notifications
Key Functionalities
User Authentication and Authorization
Subscription Tracking
Payment Monitoring
Dashboard Analytics
Renewal Reminder System
Responsive Full Stack Application
Results

The platform simplifies subscription management by helping businesses track active subscriptions, manage payments, monitor revenue, and improve customer engagement.

Conclusion

This project demonstrates a complete full stack SaaS application with secure authentication, database management, payment tracking, and analytics features suitable for modern subscription-based businesses.

How to Run
# Clone the repository
git clone <your-repository-link>

# Navigate to project folder
cd subscription-management-platform

# Install frontend dependencies
cd client
npm install

# Install backend dependencies
cd ../server
npm install

# Run backend server
npm start

# Run frontend application
cd ../client
npm start
